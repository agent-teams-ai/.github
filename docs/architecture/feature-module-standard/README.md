# Feature Module Standard

The [Feature Module Standard v1](v1.md) is the accepted immutable organization
baseline for feature-owned capability slices.

[Feature Module Standard v1.1](v1.1.md) is a minor successor that adds
sub-features and composition contracts. Its new requirements apply only to a
module that contains a sub-feature or whose profile declares a composition
contract.

Repositories adopt a version explicitly through a repository-owned local
profile. The profile maps the standard to local topology, records extensions
and deviations, and names deterministic enforcement commands. Organization
membership alone does not imply adoption.

The machine-readable version and digest registry is
[`governance/feature-module-standard.json`](../../../governance/feature-module-standard.json).
